# Canon Desktop — Print & Scan

Canon Desktop is a free Windows application for scanning documents, saving scans as PDF files, and printing documents using compatible Canon printers and scanners.

A lightweight desktop application for Canon printers and scanners.

## Features

- Scan documents using Windows Image Acquisition (WIA).
- Choose scanner resolution.
- Select input and output folders.
- Save scanned documents as PDF.
- Print documents using Windows printing capabilities.
- Remember application settings between sessions.

## Requirements

- Windows 10 or Windows 11.
- Python 3.10 or newer to run from source.
- A compatible Canon printer/scanner.
- Canon drivers installed on Windows.

## Run from Source

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install dependencies:

   ```bash
   py -m pip install -r requirements.txt
   ```

5. Run the application:

   ```bash
   py Canon_Desktop.pyw
   ```

## Download

For a ready-to-use Windows executable, visit the repository's **Releases** page.

The executable does not replace the Canon drivers. Install the appropriate drivers before using the application.
